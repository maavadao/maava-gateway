# Social Selling Playbook

Cross-category skill for social media selling strategy and post generation.

## Platform Rules

### Facebook Page
- **Max length**: Keep under 250 words for best engagement
- **Structure**: Hook → Value → CTA → Link
- **Media**: Always include an image or video. Posts with visuals get 2.3x more engagement.
- **Posting times**: Tues-Thurs, 9am-12pm seller's timezone
- **Frequency**: 3-5 posts/week, never more than 2/day
- **CRITICAL**: We post to Facebook **Pages** only, NOT personal timelines

### Instagram
- **Caption**: 150 words optimal, up to 2200 chars
- **Hashtags**: 15-20 relevant, mix of popular + niche
- **Structure**: Hook line → Story → Features → CTA → Hashtags (separated by line breaks)
- **Stories**: Use polls, questions, countdowns for engagement

### LinkedIn
- **Tone**: Professional, thought-leadership angle
- **Structure**: Personal insight → Problem → Solution (your product) → Soft CTA
- **Length**: 150-300 words
- **No hashtags in body** — add 3-5 at the end
- **Best for**: B2B, SaaS, consulting, professional services

## Post Types & When to Use

| Post Type | When | Template |
|-----------|------|----------|
| Launch announcement | New product | "Introducing [Product]...\n\nAfter [X] months of work..." |
| Feature spotlight | Weekly | "Did you know [Product] can...?" |
| Social proof | After good feedback | "[Quote from buyer]\n\nThis is why I built..." |
| Behind-the-scenes | Weekly | "Here's how I [created/designed/built]..." |
| Limited-time offer | Promotions | "🔥 [X]% off for the next [Y] hours..." |
| Still available | 3-7 days post-launch | "Still looking for [solution]? [Product] is..." |
| FAQ/objection handler | As needed | "I get asked this a lot: [question]\n\nHere's the answer..." |

## Recurring Promotion Patterns

### Launch Sequence (recommended for every new product)
1. **Day 0**: Launch announcement (all channels)
2. **Day 1**: Feature deep-dive (Facebook + LinkedIn)
3. **Day 3**: Social proof or behind-the-scenes (Instagram + Facebook)
4. **Day 7**: "Still available" reminder
5. **Day 14**: Final push / limited offer

### Evergreen Rotation (for active products)
- Week 1: Feature spotlight
- Week 2: Use case / customer story
- Week 3: Behind-the-scenes
- Week 4: Promotional offer

## Copy Formulas

### Hook Formulas
- "Stop [bad thing]. Start [good thing]."
- "I spent [time] building the [product] I wish existed."
- "[Surprising stat]. Here's how to fix it →"
- "If you [pain point], you need this."

### CTA Formulas
- Direct: "Get it here → [link]"
- Soft: "Check it out and let me know what you think"
- Urgent: "Only [X] left at this price"
- Social: "Tag someone who needs this"

## Approval Rules

Before publishing:
1. Always generate a **preview** for the seller
2. If `approval_required = true`, create an approval request
3. Never auto-publish to a new channel without explicit consent
4. For recurring promotions, get approval on the **template** first, then auto-publish variants

## Multi-Channel Adaptation

When given a listing, always generate variants for each connected channel. Adapt:
- Length (Facebook: longer → Instagram: shorter → Story: shortest)
- Tone (LinkedIn: professional → Facebook: balanced → Instagram: visual-first)
- Hashtags (none on Facebook → 3-5 on LinkedIn → 15-20 on Instagram)
- CTA style (LinkedIn: soft → Facebook: direct → Instagram: link-in-bio)
